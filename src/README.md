# 📦 Dossier src/

Ce dossier contient le code source du package **packages-python**.

### Structure
- `packages_python/` : module principal du package
  - `__init__.py` : expose les fonctions du module
  - `core.py` : logique interne (exemple : fonction add)

### Objectif
Fournir un package Python simple, clair et facilement extensible.
